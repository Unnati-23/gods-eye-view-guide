Open Source

Put a Spy Satellite
in Your Browser

God's Eye View is a spy-satellite simulator that runs in your browser — except the data is real. Live open-source spatial intelligence on a photorealistic 3D globe: satellites, flights, vessels, wildfires and rocket launches. It's free, fully open source, and boots with zero API keys. Here's how to get it running on your own machine in about five minutes.

Source: Get God's Eye View on GitHub →
https://github.com/bilawalsidhu/gods-eye-view

The 5-Minute Setup

Run It on Your Machine

No keys needed

The app starts fully keyless on a free satellite basemap (Esri World Imagery). API keys are upgrades, not prerequisites — you can add them later to unlock live flights, ships, wildfires and voice. Start first, power up when you want.

Before you start

  • Node.js 24.x (24.14.0 or later) or 26.x. Avoid Node 25 — it's end-of-life.
  • Git — to clone the repository.
  • Any terminal (macOS Terminal, iTerm, Windows PowerShell, or the built-in terminal inside your editor).

Install it — copy & paste

1
Clone & boot

Run these in order

# clone the repo and enter the folder git clone https://github.com/bilawalsidhu/gods-eye-view.git cd gods-eye-view # install exactly what's pinned, then run the setup check npm ci npm run doctor # start it npm run dev
2
Open it

When the server says ready, open this in your browser:

http://localhost:4173 →

Pick a starting mode — Live Contacts, Space Missions, Environmental, or Explore Manually — and start spinning the globe.

Open it in your editor or AI agent

Prefer to work on it in Claude Code, Cursor, Codex, or VS Code? Clone it first (Step 1), then open the folder in whichever tool you use and run npm run dev from its built-in terminal.

Claude Code

cd gods-eye-view claude

Starts Claude Code inside the repo. Then run npm run dev.

Cursor

cd gods-eye-view cursor .

Or open the folder from Cursor's UI, then run npm run dev in its terminal.

OpenAI Codex CLI

cd gods-eye-view codex

Launches the Codex agent in the project. Then run npm run dev.

VS Code

cd gods-eye-view code .

Opens the project, then run npm run dev in the integrated terminal.

macOS tip

On a Mac, ./scripts/dev-fresh.sh clears the Vite cache and pulls any keys from your Keychain — handy if a restart ever looks stale.

Optional power-ups

Everything below is optional. Add keys in-app via the POWER UP chip (bottom-right) → Provider Settings:

  • OpenSky — real live flight tracking
  • AISStream — live ship & vessel positions
  • NASA FIRMS — active wildfire detections
  • OpenAI — voice control (talk to the map)
  • Cesium ion / Google Maps — higher-res 3D terrain & imagery
